# 路线图

路线图按“教学价值优先”排序，而不是按技术复杂度排序。

## v0.1.0 — 可课堂使用的沙盒（已完成）

- [x] 三个渐进式实验。
- [x] 提交图、分支标签、HEAD。
- [x] 冲突对照与解决选择。
- [x] 本地进度保存。
- [x] 键盘快捷键与专注模式。
- [x] 状态机单元测试。
- [x] MIT 许可证、贡献指南、Issue / PR 模板。

## v0.2.0 — 可分享的练习

- [ ] 把当前实验与步骤编码进 URL，支持“我卡在这一步”的分享。
- [ ] 完成后生成一张提交图卡片，可下载为 PNG。
- [ ] 增加“命令历史”面板，支持回退到任意步骤。
- [ ] 移动端提交图手势缩放。

## v0.3.0 — 教师模式

- [ ] 通过 JSON 导入自定义课程脚本。
- [ ] 教师可导出课堂练习包（含答案与常见错误）。
- [ ] 增加“删除/重命名冲突”实验。
- [ ] 课程脚本 schema 与校验工具。

## v1.0.0 — 连接真实仓库

- [ ] 通过 GitHub API 读取公开仓库的提交图（只读）。
- [ ] 把沙盒中的操作映射为真实仓库的练习清单。
- [ ] 可选的账号同步（仅保存进度，不收集个人信息）。

## 不做

- 完整的 Git 客户端。
- 在线代码执行环境。
- 付费课程平台。
- 以增长为目标的社交功能。
